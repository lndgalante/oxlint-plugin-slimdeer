# 0.6.3

Bug fixes and faster, lighter runs. The engine and the cache format are unchanged, so cached results carry over and nothing is measured again.

- **Single-pass cold `--review`.** With nothing cached yet, `npx oxlint-plugin-slimdeer --review` now saves each same-format preview while measuring instead of compressing every listed image a second time. On `example/`'s five images with a cold cache, `--review` dropped from 9.6 s to 4.7 s. After a lint or `--check`, `--review` still compresses each listed image once for its preview, and a second review still reuses existing previews.
- **Lighter worker pool memory.** Finished worker lanes now terminate their WebAssembly engine as soon as no jobs remain, instead of holding its memory until slower images finish. The memory budget's estimate for PNGs below 8 MP is raised from 125 to 180 bytes per pixel (1.3–2.3 MP PNGs in `bench/.images` peaked at 163–179 bytes per pixel above Node and the engine's base; 9–12 MP PNGs stay at 85, where slimdeer uses its lean reference).
- **Fewer missed images and false positives:**
  - Spec-legal JPEGs with `0xFF` fill bytes before markers (and standalone markers before the scan) are read, marked and compressed instead of skipped as `"unreadable header"`.
  - `srcSet` parsing now requires each candidate to be a single path or a path with an HTML width/density descriptor (`400w`, `1.5x`), so prose strings starting with an image path (`"/hero.png is used in the header"`) aren't flagged.
  - Percent-escaped filenames with reserved URI characters (`%23`, `%26`, `%2B`) resolve to local files while keeping `%2F` and `%5C` from turning into folder separators.
  - `tsconfig.json` `references` keep checking later referenced configs when an earlier one has `paths` with no folder aliases.
- **Early CMYK JPEG detection.** 4-component CMYK JPEGs are now caught from their frame header before starting WebAssembly (`a CMYK JPEG (convert it to RGB)`), cached as skipped, and included in `--check`'s `--exclude` suggestion.
- **Review page fixes.** EXIF-rotated photos already loaded from cache when the script runs now get their rotated aspect ratio right away, and touch taps clean up their `pointermove`, `pointerup` and `pointercancel` listeners.
- **Summary and job summary consistency.** Lossless results now read `lossless` in the lint summary table and GitHub Actions job summary (instead of `100`), the summary shares path-matching logic with `mentions.js` so `img/hero.png` in a sibling stylesheet doesn't match `public/hero.png`, and fenced command blocks in Markdown job summaries fence past backticks in filenames.

The engine is unchanged: slimdeer 0.3.1, the same files as 0.6.0. [What 0.6.0 brought](https://github.com/lndgalante/oxlint-plugin-slimdeer/blob/main/docs/releases/0.6.0.md)
